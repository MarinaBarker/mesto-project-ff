# Проектная работа Mesto

<h2>Краткое описание:</h2>
<p>"Mesto" - это интерактивная страница, где пользователи могут публиковать фотографии и лайкать их.</p>

<a href="https://marinabarker.github.io/mesto-project-ff/">Открыть сайт</a>

<div> Функционал:
<li>Редактирование профиля</li>
<li>Добавление новой фотографии (карточку можно добавить, нажав Enter, находясь в одном из текстовых полей)</li>
<li>Удаление карточки при клике на иконку</li>
<li>Поставить / убрать лайк</li>
<li>Открытие фотографии в полном размере</li>
</div>

<div>
<h2>Технологии, использованные при создании:</h2>
<li>Flexbox</li>
<li>Grid Layout</li>
<li>CSS - animation</li>
<li>Методология BEM</li>
<li>Файловая структура BEM Nested</li>
<li>JavaScript (OOP, Asynchronous JS, DOM API, Fetch API)</li>
<li>Валидация форм на стороне пользователя</li>
<li>Адаптивная верстка (мобильные устройства, планшеты, десктопы)</li>
<li>Webpack</li>
</div> <br>
<p>Проект сверстан по методологии BEM. При верстке приоритетно использована технология Grid Layout, местами используется flexbox. Все интерактивные элементы анимированы. Все контентные блоки, включая блок с карточками, контентонезависимы.</p>

<h2>Языки:</h2>
<li>HTML</li>
<li>CSS</li>
<li>JavaScript</li>

<h2>Локальная установка:</h2>
В командной строке перейдите в папку, где будет развернут проект. После чего скопируйте его с GitHub:<br>
`$ git clone git@github.com:MarinaBarker/mesto-project-ff.git` <br>
Далее переходим в папку с проектом и устанавливаем компоненты: <br>
`$ npm install` <br>
После этого нужно собрать проект: <br>
`$ npm run build` <br>
Далее можно запускать проект на локальном сервере: <br>
`$ npm run dev`
